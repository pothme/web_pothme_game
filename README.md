# 포듬증권 — 함께 읽는 시장

최대 50명이 함께 이용하는 3D 증권사 사무실과 전략 게임룸입니다. 정면·후면에 네 개씩 있는 시장 차트, 커뮤니티 인기글, 공개 채팅·귓속말, 소파·스낵바와 캐릭터 액션을 제공합니다. 입장 시 내 캐릭터를 따라가며 모바일에서는 차트·사무실·게임룸을 전환할 수 있습니다.

## 현재 소스와 빠른 시작

이 저장소는 [운영 중인 포듬증권](https://podeumgo.podeumgo.workers.dev/)의 소스입니다. 최신 반영 사항은 60층 멀티플레이 점프 타워, 타워 채팅, 함정 넉백·충격 이펙트·효과음, 모바일 원형 조이스틱입니다. 최근 전체 테스트 **379개**와 TypeScript 검사·프로덕션 빌드를 통과했습니다. 아래 날짜별 기록은 각 배포 당시의 상태이며, 최신 변경 내역은 문서 하단에 이어집니다.

Node.js 22.15 이상과 npm이 필요합니다.

```sh
git clone https://github.com/pothme/web_pothme_game.git
cd web_pothme_game
npm ci
npm test
npm run build
node test/preview.mjs
```

마지막 명령은 실제 공개 데이터와 분리된 로컬 테스트 서버를 `http://127.0.0.1:8890/`에 엽니다. 종료할 때 해당 터미널에 `quit`를 입력합니다. 소스를 변경하며 개발하려면 `npm run dev:server`와 `npm run dev`를 별도 터미널에서 실행하고 `http://127.0.0.1:5173/`에 접속합니다.

- `src/`: Three.js 사무실·캐릭터·게임·모바일 UI
- `shared/`: 공통 모델·게임 물리·카탈로그·규칙
- `server/`: Cloudflare Worker·실시간 연결·SQLite 저장·관리자 인증
- `test/`: 자동 테스트와 로컬 테스트 서버
- `dev/`: 개발 전용 캐릭터 미리보기
- `wrangler.jsonc`, `wrangler.charts.jsonc`: 메인 서버와 보조 차트 Worker 배포 설정

현재 배포 설정은 기존 운영 계정·주소를 가리킵니다. 다른 계정에 배포하려면 Worker 이름, 공개 주소, 관리자 이메일, Google OAuth 클라이언트와 차트 제공자 도메인 등록을 해당 환경에 맞춰 설정해야 합니다. Google 로그인용 `GOOGLE_CLIENT_SECRET`, 사용량 조회용 `CLOUDFLARE_ANALYTICS_TOKEN`은 Cloudflare Worker secret으로 별도 등록하며 Git에 포함하지 않습니다. 현재 관리자 인증은 Google 모드로, 예전 비밀번호 설정 스크립트는 이전 운영 방식용입니다.

로컬 자격증명·환경 파일·DB 상태, 설치된 패키지, 빌드 결과, 운영 로그와 화면 캡처는 `.gitignore`로 제외했습니다. 아래 이력에서 참조하는 `artifacts/` 및 `outputs/`는 운영 PC에만 있는 검증 자료입니다.

실내 벽 보드는 가로 약 73.48 × 세로 15.92로 직전 버전 면적의 2배입니다. 2400 × 520px 화면 비율을 유지합니다. 실내는 약 85.28 × 75.73으로 바닥 면적도 직전 버전의 2배이며 가구·캐릭터 크기는 유지하고 책상 10개 간격을 넓힙니다. 레이아웃 버전은 5입니다. ‘차트 보기’는 렌즈가 방 밖으로 나가지 않는 범위에서 보드 정면을 잡습니다.

## 포듬 시세 / 만석 자동 이동

`/markets`는 포듬증권의 별도 시세 페이지입니다. 참고 사이트의 시세표 구성을 참고해 직접 만든 화면으로, 외부 사이트의 소스·로고·차트를 복제하지 않습니다. Upbit KRW와 Binance USDT의 공통 20개 코인 가격, 등락률, 거래대금, 검색·정렬·브라우저 즐겨찾기와 BTC 차트를 제공합니다.

`/api/quotes`는 공식 공개 API를 사용합니다. 가격은 60초마다 갱신하고 공급자별로 공유 캐시·요청 병합·시간 제한을 적용합니다. USD/KRW는 Frankfurter의 일별 기준 환율이며 실시간 환율로 표시하지 않습니다. 김치프리미엄은 `업비트 원화 ÷ (바이낸스 USDT × USD/KRW) − 1`로 계산한 참고값입니다. 1 USDT = 1 USD 가정과 환율 기준일을 표시하며 실제 Upbit USDT/KRW는 별도 카드에 표시합니다. 공급자 연결 실패·과거 수신값은 시각과 함께 구분하며 가짜 숫자를 채우지 않습니다. 공개 Cloudflare에서 Binance HTTP403을 확인해, 서버 수신 실패 시 같은 공식 공개 API를 브라우저가 일반 CORS 요청으로 직접 받도록 보완했습니다. 브라우저 수신 주체와 시각을 표시하며 인증·프록시·대체 호스트를 사용하지 않습니다. 직접 수신도 실패하면 이전 값 또는 미수신 표시를 유지합니다.

정원은 20명입니다. `/api/admission`은 쿠키 신원에 따라 재접속·차단·폐쇄·만석을 확인합니다. 21번째 신규 방문자는 `/markets?reason=full`로 이동합니다. 마지막 자리 동시 입장으로 WebSocket 연결이 거절되면 입장 상태를 다시 확인해 이동합니다. 기존 신원의 재접속은 정원 때문에 밀려나지 않습니다. 시세 페이지는 사무실 인원에 포함되지 않으며 사무실로 돌아가는 링크를 제공합니다.

## 커피값 후원

사무실과 시세 페이지에 ‘커피값 후원하기’가 있습니다. 관리 화면에서 본인 카카오페이 송금 URL을 등록하면 두 화면이 같은 주소를 사용합니다. `https://qr.kakaopay.com/…` 또는 `https://link.kakaopay.com/…`만 허용하며 빈 값은 미등록 상태입니다. 현재 실제 주소를 제공받지 않았으므로 임의 수취인이나 가짜 결제 링크는 넣지 않습니다.

카카오톡 더보기 → 상단 코드스캔 → 하단 송금코드에서 본인 QR을 확인합니다. 공유 링크를 복사하거나 QR 이미지의 주소를 사용해 관리 화면에 등록할 수 있습니다. [카카오페이 공식 안내](https://contents.kakaopay.com/contents/2325). 후원은 외부 카카오페이에서 사용자가 수취인·금액을 확인하고 진행하며 앱은 결제 비밀번호·카드 정보·송금 내역을 수집하지 않습니다.

## 입장·이동·대화

- 닉네임 2–12자, 동시 접속 최대 20명입니다. 접속 중인 닉네임은 중복 사용할 수 없습니다.
- 바닥 클릭, WASD 또는 방향키는 캐릭터를 이동합니다. 서버는 이동을 실내 범위 `shared/classroom-layout.ts`의 확장된 경계와 보행 속도로 제한합니다. 좌석·일어나는 위치·재접속 위치도 방 안에 있습니다. 카메라는 중앙 통로의 자유 시점으로 시작하므로 캐릭터가 걸어가거나 자리를 바꿔도 보고 있던 위치를 유지합니다.
- 드래그로 카메라를 회전하고, 오른쪽 버튼 드래그·Shift+드래그·두 손가락으로 화면을 옮깁니다. 휠·핀치 또는 확대·축소 버튼으로 거리를 조절합니다. 화면의 ←↑↓→는 카메라 이동 버튼이며 캐릭터 이동 키와 구분됩니다. 모바일 상단 ‘도구’에서도 이동·회전 버튼을 사용합니다.
- 카메라 렌즈는 벽·바닥·천장의 안쪽에 유지됩니다. ‘내 캐릭터’를 누르면 따라가기를 켜고, 벽 모서리에서 거리가 부족하면 방 안쪽에서 캐릭터를 바라보는 위치를 사용합니다. 화면을 옮기거나 ‘자유 시점’을 선택하면 따라가기가 해제됩니다. ‘차트 보기’는 실내에서 벽의 차트 보드 정면으로 한 번에 이동하는 시점 버튼입니다.
- Enter 또는 채팅 입력창으로 80자까지 대화합니다. 말풍선은 캐릭터 머리 위에 8초 동안 표시합니다. 최근 대화 30개는 화면에서만 보이며 영구 보관하지 않습니다.
- 모바일은 차트·사무실 전환 화면입니다. 가로 4개 보드가 48px 상단 바와 56px 하단 메뉴 사이를 사용합니다. 각 차트는 화면 폭에 따라 최소 폭을 280–320px로 확보하고 좌우로 스크롤합니다. ‘이전 차트’·‘다음 차트’ 버튼으로 옆 칸을 보거나 번호·↗ 버튼으로 한 종목을 크게 볼 수 있습니다. 세로·가로 화면 모두 한 줄 배치를 유지합니다.
- 하단 메뉴에서 사무실·차트 안내·입장/채팅을 열고, 상단 ‘도구’에서 시점을 조절합니다. 입장·안내·도구 창은 누를 때만 열리며, 키보드가 차지한 공간을 제외한 높이에 맞춰 스크롤됩니다.
- 모바일 사무실 화면에서는 최근 채팅 3개만 작게 표시하고, 차트 화면에서는 접힌 채팅 기록을 숨깁니다. ‘채팅’ 또는 Enter로 입력 화면을 열고 닫기나 Escape로 접습니다. 초안은 유지되며 전송 완료 후 새로 작성한 내용이 없으면 자동으로 접힙니다. 차트·사무실을 전환해도 차트 연결을 유지하고, 차트를 보는 동안 숨겨진 3D 장면의 그리기를 멈춥니다.
- 빈 의자를 누르거나 ‘의자 선택’에서 자리를 고릅니다. 이동 키 또는 ‘일어나기’로 일어납니다. 사용 중인 자리는 중복 착석할 수 없습니다.
- 브라우저의 HttpOnly 접속 쿠키로 신원을 구분합니다. 같은 브라우저의 여러 탭에서는 마지막 입장 탭이 연결을 소유합니다. 쿠키를 삭제하거나 다른 기기로 접속하면 다른 신원입니다.

기존 미니게임, 강도 추격전, 용돈 드롭, NPC, 지갑 표시, 유료 칠판과 빵 장식은 서비스에서 제거했습니다. 과거 지갑·칠판 SQL 기록은 보존하지만 신규 보상·차감·벌금은 발생하지 않습니다. 실제 주문이나 결제 기능은 없습니다.

## 개발자 관리

관리 비밀번호는 이 PC의 `.local/admin-access.json`에 보관하며 공개 파일에는 포함하지 않습니다. Cloudflare `ADMIN_PASSWORD` Worker secret과 일치해야 합니다. 일반 참가자의 닉네임이나 브라우저 저장값은 관리 권한을 부여하지 않습니다.

- **사무실 닫기:** 신규 입장을 막고 접속자 모두 퇴장시킵니다. 네 칸의 선택 종목과 운영 설정을 보존합니다.
- **사무실 열기:** 다시 입장할 수 있습니다. 게임이나 돈 지급은 시작하지 않습니다.
- 네 종목 검색·배치와 분봉(1·5·15·60분·일봉)을 저장합니다. 참가자의 과거 `chart-propose`/`chart-vote` 메시지는 서버에서 거부합니다.
- 공지(200자), 후원 주소, 채팅 허용 여부를 설정합니다.
- 접속자·좌석 목록을 확인하고 개별 퇴장, 60분 입장 제한, 제한 해제를 실행합니다. 제한은 브라우저 쿠키 신원 기준으로, 로그인 계정이나 기기 전체를 식별하는 차단은 아닙니다.
- 최근 대화 비우기와 운영 기록 최근 80건을 제공합니다. 기록에는 비밀번호·채팅 원문을 담지 않습니다.
- 모든 변경은 관리자 세션·동일 출처·CSRF 검증을 통과해야 하며 비동기 검증 후 인증 상태를 다시 확인합니다.

관리 페이지는 같은 Worker에서 동작합니다. 닫기는 입장과 활동을 중단하는 것이며 Worker 자체나 공개 정적 페이지를 삭제하지 않습니다. 필요한 경우 `node scripts/configure-admin.mjs`로 로컬 관리 비밀번호를 Worker secret에 다시 반영합니다. 기존 비밀번호가 있으면 그대로 사용합니다.

Node.js 22.15 이상을 사용합니다.

```powershell

npm.cmd ci

npm.cmd run preview
```

로컬 미리보기는 http://127.0.0.1:8787 입니다. 로컬 데이터와 공개 서버 데이터는 분리됩니다. 개발 시 `npm.cmd run dev:server`와 `npm.cmd run dev`를 별도 터미널에서 실행하면 Vite의 http://127.0.0.1:5173 에서 작업할 수 있습니다.


보조 차트 Worker를 먼저 배포하고 메인 Worker를 배포합니다. `wrangler.charts.jsonc`의 `podeumgo-charts` Worker는 Free 플랜으로 배포되어 있으며, 국내 차트의 외부 스크립트를 메인 서비스와 다른 도메인에서 실행합니다. 공식 Vunelix 웹 컴포넌트를 사용하고 제공자 출처 표시는 유지합니다. 시세를 스크래핑하거나 자체 시세 API로 재배포하지 않습니다.

Vunelix 계정에 `podeumgo-charts.podeumgo.workers.dev` 도메인을 등록했고 Verified 상태를 확인했습니다. 이 호스트에서 삼성전자와 코스닥 알테오젠의 실제 캔들을 확인한 뒤 메인 Worker의 `KOREAN_CHARTS_ENABLED`를 문자열 `true`로 설정했습니다. 배포 주소가 바뀌면 새 위젯 호스트도 등록·검증하고 공개 주소에서 표시를 확인해야 합니다. API 키나 유료 요금제로 전환하지 않았습니다.

기존 `wrangler.jsonc`의 Worker 이름, `CLASSROOM` 바인딩, `Classroom` 클래스와 마이그레이션 태그를 유지해야 기존 관리 세션·운영 상태·데이터가 보존됩니다. 별도 유료 데이터 API나 데이터베이스를 추가하지 않았습니다. TradingView와 Vunelix의 출처 표시는 유지합니다.

Free 플랜에는 요청·저장 한도가 있습니다. 이동은 움직일 때 초당 최대 1회만 전송하고 매 이동을 SQL에 저장하지 않으며, 빈 방에는 반복 알람을 두지 않습니다. 계정의 다른 사용량과 공개 접속량에 따라 무료 한도에 도달하면 서비스가 제한될 수 있습니다. 플랜을 유료로 전환하지 않습니다.

## 검증과 소스

현재 변경은 전체 자동 테스트 **93개**와 프런트·서버 TypeScript 빌드를 통과했습니다. 로컬 브라우저에서 관리자 분봉 변경의 실시간 전파, 공지·채팅 중지·재개·대화 비우기, 20명 만석 뒤 `/markets?reason=full` 이동, 시세 검색·관심 코인 저장을 확인했습니다. 320×844/390×844 프레임에서 차트 표시·입장·채팅 후 접기·착석, 844×390 가로 화면의 차트·메뉴 영역을 확인했습니다. 실제 안드로이드 단말/IME 검증은 아닙니다. 공개 사무실에서 삼성전자·SK하이닉스·BTC·SOXL 네 1분봉과 위·아래 시세띠를 확인했습니다. 공개 `/markets`에서도 Upbit·Binance 브라우저 수신·기준 환율의 정상 상태와 BTC 가격·프리미엄 표시를 확인했습니다. 스크린샷은 `artifacts/public-office-one-minute.png`, `artifacts/public-podeum-markets.png`에 보관합니다.
